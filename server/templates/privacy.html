Drishti Privacy Policy

Effective date: 12 November 2026

Drishti is a privacy-focused browser assistant. It accesses browser content only to perform tasks requested by the user and attempts to detect and mask sensitive information locally before cloud-based reasoning.

1. Who operates Drishti

Drishti is the SIH26171 project team's browser agent, maintained by Uppala Mahesh. Questions, privacy concerns, and deletion requests can be raised at github.com/Uppala-mahesh/sih26171/issues.

2. Information Drishti processes

When you explicitly ask Drishti to inspect a page or complete a browser task, the extension may process:

  • Your command and task preferences.
  • The URL, title, visible text, page structure, interactive elements, and navigation state of pages involved in the requested task.
  • Locally redacted screenshots when visual understanding is needed.
  • Task events, action results, confirmations, errors, and security/audit records.
  • A randomly generated installation credential and technical session identifiers used to isolate your browser connection from other users.
  • Settings and limited chat/task history stored locally through Chrome storage.

Depending on the website and task, page content may include personal communications or information you entered into a page. Drishti is designed to detect and mask common sensitive fields locally, but automated redaction cannot be guaranteed to identify every sensitive value.

3. How information is used

Information is used only to provide and secure the browser-assistant functionality requested by the user, including understanding the current page, planning actions, enforcing safety policies, requesting confirmation, executing permitted actions, verifying results, diagnosing failures, and maintaining tamper-evident task records.

4. Local processing and cloud reasoning

Sensitive-data detection, DOM redaction, screenshot masking, QR suppression, OCR verification, and visual grounding run inside the extension using packaged code and models. The companion Drishti server runs on the same machine at 127.0.0.1 by default and receives only the sanitized context the extension has already produced. It is not a hosted Drishti backend and does not require an account.

For planning and reasoning, sanitized context may be sent over HTTPS to the AI model provider configured by the user, such as Google Gemini, Groq, OpenRouter, or OpenAI. A raw screenshot is never sent: the extension sends only the masked image, and withholds it entirely if its own re-OCR pass finds residual personal data. Drishti does not download or execute remote JavaScript or WebAssembly; cloud responses are structured, non-executable data interpreted by fixed local logic.

5. Sharing and sale of data

Drishti does not sell user data and does not use browser data for personalized advertising, retargeting, credit decisions, or unrelated profiling. Data is transferred to service providers only when necessary to provide the user-requested functionality, maintain security, comply with law, or investigate abuse. Service providers process data under their own applicable terms and privacy policies.

6. Storage and retention

Extension preferences, installation credentials, and limited interface history may remain in Chrome storage until you clear the extension's data or uninstall it. The local server writes task audit records to the user's own machine under ~/.drishti/tasks; those files remain until the user deletes them. Drishti does not operate a remote account database for this build, so there is no server-side retention period to request.

7. Security

The local Drishti server binds to loopback only, so it is not reachable from other machines on the network. Each extension installation uses an independent high-entropy credential so its browser connection, task registry, and event stream are isolated. Connections from the extension to the local server use loopback WebSocket; connections from the local server to a cloud model provider use HTTPS. No method of storage or transmission is completely secure, and users should avoid asking the extension to process information that is not necessary for their task.

8. User choices and deletion

You control when Drishti is invoked and which tasks it performs. Sensitive actions may require your confirmation. You can stop using the service, clear extension storage, or uninstall the extension at any time. To delete local task records, remove the ~/.drishti directory on your machine. Because this build has no hosted account, there is no remote profile to delete.

9. Children's privacy

Drishti is not directed to children under 13 and is not intended to knowingly collect personal information from children.

10. Changes to this policy

This policy may be updated when Drishti's functionality or data practices change. Material changes will be reflected on this page with an updated effective date and, where required, disclosed in the product interface.

11. Chrome Web Store Limited Use

Drishti's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Chrome API data is used only to provide or improve the extension's single, user-facing purpose and is not transferred for advertising or unrelated purposes.
